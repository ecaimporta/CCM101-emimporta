# Mission 7: The Cloud Operations Engineer

## Mission Overview

This laboratory activity focuses on monitoring Linux host resources, deploying an Nginx container, generating HTTP traffic, and examining application logs and container metrics.

## Objectives

- Monitor host memory and disk capacity.
- Observe running processes and CPU load.
- Deploy an Nginx container named `client-website`.
- Generate successful and unsuccessful HTTP requests.
- Inspect application logs and container resource metrics.

## Monitoring Commands Executed

- `free -h` — checks memory usage.
- `df -h /` — checks root filesystem capacity.
- `top` — displays running processes and CPU activity.
- `docker ps` — lists running containers.
- `curl` — sends HTTP requests.
- `docker logs client-website` — displays container logs.
- `docker stats` — displays container resource metrics.

## Skills Learned

This activity developed skills in Linux system monitoring, Docker deployment, HTTP testing, application log analysis, and container resource monitoring.
