# Amazon Web Services (AWS) Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides different services organizations can access through the internet. It allows businesses to use computing resources without maintaining all physical infrastructure themselves.

## Global Infrastructure

AWS operates a worldwide cloud infrastructure made up of geographic Regions and Availability Zones. Regions are separate geographic areas, while Availability Zones are isolated locations within those Regions.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS resources. Users can create, configure, monitor, and manage different AWS services through the console.

## Four Core Services

### Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual computing resources in the cloud. It can be used to run applications and servers.

### Amazon S3

Amazon Simple Storage Service (S3) is an object storage service used for storing and retrieving files, backups, application data, and other digital content.

### Amazon VPC

Amazon Virtual Private Cloud (VPC) allows users to create an isolated virtual network for AWS resources.

### AWS IAM

AWS Identity and Access Management (IAM) helps control access to AWS resources by managing users, roles, and permissions.

## Three Advantages

- AWS provides a wide selection of cloud services.
- Its global infrastructure can support users from different locations.
- Cloud resources can be scaled depending on changing requirements.

## Typical Enterprise Use Cases

AWS can be used for hosting websites and applications, storing business data, running enterprise workloads, deploying databases, and supporting scalable online services.
