# Client Recommendations

## Client A - Startup Company

### Client Situation

A startup company wants to launch a new mobile application. Their budget is limited, but they expect rapid growth within the next few years.

### Recommended Cloud Provider

**Google Cloud**

### Reasoning

Google Cloud is a suitable option because the startup needs an environment that can support its current application while still allowing room for future growth. This recommendation considers both its limited starting resources and its expected expansion.

### Recommended Services

- Firebase
- Compute Engine
- Cloud Storage

## Client B - University

### Client Situation

A university already uses:

- Windows Server
- Microsoft 365
- Active Directory

The university wants to migrate some services to the cloud.

### Recommended Cloud Provider

**Microsoft Azure**

### Reasoning

Azure is a practical choice because the university already uses Microsoft technologies. Using Azure can support a smoother transition while allowing the university to migrate selected services gradually.

### Recommended Services

- Azure Virtual Machines
- Microsoft Entra ID
- Azure Blob Storage

## Client C - AI Research Company

### Client Situation

A research company develops Artificial Intelligence and Machine Learning applications that require high-performance computing.

### Recommended Cloud Provider

**Google Cloud**

### Reasoning

Google Cloud is suitable because the company's main workloads involve artificial intelligence and machine learning. It provides specialized services that can support AI development and high-performance computing requirements.

### Recommended Services

- Vertex AI
- Compute Engine
- Google Kubernetes Engine (GKE)

## Client D - Global E-Commerce Company

### Client Situation

A multinational online shopping company serves customers around the world and requires highly available infrastructure with automatic scaling.

### Recommended Cloud Provider

**AWS**

### Reasoning

AWS is suitable because the company needs infrastructure that can support global users and changing levels of traffic. Its services can distribute requests and automatically scale computing resources when demand increases.

### Recommended Services

- Amazon EC2
- Elastic Load Balancing
- EC2 Auto Scaling

# Cloud Provider Decision Matrix

| Organization / Requirement | Recommended Provider | Reason |
|---|---|---|
| Startup Company | Google Cloud | Can support application development and future growth. |
| Enterprise Organization | AWS | Provides a broad range of services for different enterprise workloads. |
| Microsoft Environment | Microsoft Azure | Integrates well with existing Microsoft technologies. |
| AI / Machine Learning | Google Cloud | Provides specialized AI and machine learning services. |
| Kubernetes Deployment | Google Cloud | Provides Google Kubernetes Engine for managed Kubernetes workloads. |
| Global Web Application | AWS | Provides global infrastructure and scalable cloud services. |
