# Microsoft Azure Research

## Brief Overview

Microsoft Azure is Microsoft's cloud computing platform. It provides cloud services that organizations can use to build, deploy, and manage applications and IT resources.

## Global Infrastructure

Azure operates cloud infrastructure across many geographic regions around the world. Organizations can select suitable locations for their applications and data based on their requirements.

## Cloud Management Console

The Azure portal is a web-based interface used to manage Azure services and resources. Users can create virtual machines, configure networks, manage storage, and monitor resources.

## Four Core Services

### Azure Virtual Machines

Azure Virtual Machines provides virtualized computing resources for running Windows or Linux workloads.

### Azure Blob Storage

Azure Blob Storage is an object storage service that can store documents, images, videos, backups, and application files.

### Azure Virtual Network

Azure Virtual Network provides private networking for Azure resources and allows cloud resources to communicate securely.

### Microsoft Entra ID

Microsoft Entra ID provides identity and access management capabilities for users and applications.

## Three Advantages

- Azure integrates well with Microsoft technologies.
- It supports both Windows and Linux workloads.
- It provides global cloud infrastructure for organizations.

## Typical Enterprise Use Cases

Azure can be used for migrating business systems to the cloud, hosting applications, storing organizational data, supporting hybrid environments, and managing identities.
