# Cloud Platform Comparison

| Category | AWS | Microsoft Azure | Google Cloud |
|---|---|---|---|
| Launch Year | 2006 | 2010 | 2008 |
| Compute Service | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage Service | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking Service | Amazon VPC | Azure Virtual Network | Google Cloud VPC |
| Identity Service | AWS IAM | Microsoft Entra ID | Cloud IAM |
| Primary Strength | Broad selection of cloud services | Microsoft technology integration | Data, AI/ML, and Kubernetes |
| Ideal Organizations | Organizations needing broad and scalable cloud services | Organizations already using Microsoft technologies | Organizations focused on AI, data, and containers |

# Comparison Questions

## 1. Which provider offers the broadest range of cloud services?

AWS offers a broad range of cloud services for computing, storage, networking, databases, security, analytics, and many other workloads.

## 2. Which provider integrates best with Microsoft environments?

Microsoft Azure is the most suitable for organizations already using Microsoft technologies because it can connect well with existing Microsoft systems and services.

## 3. Which provider is strongest in AI and Kubernetes technologies?

Google Cloud is a strong option for artificial intelligence, machine learning, and Kubernetes because it provides specialized AI services and Google Kubernetes Engine.

## 4. Which cloud provider would you personally choose and why?

I would personally choose AWS because I want to become more familiar with a platform that provides many different cloud services. What interests me most is learning how separate AWS services can work together in one cloud environment. Exploring AWS further could also help me understand different areas of cloud computing instead of focusing on only one type of service.
