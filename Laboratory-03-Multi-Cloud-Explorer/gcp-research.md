# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud is a cloud computing platform that provides infrastructure, data, application, and cloud services for organizations.

## Global Infrastructure

Google Cloud operates global infrastructure organized into regions and zones. Organizations can choose locations for their resources based on performance, availability, and user location.

## Cloud Management Console

The Google Cloud console is a web-based interface used to create, manage, and monitor Google Cloud resources.

## Four Core Services

### Compute Engine

Compute Engine provides virtual machines that run on Google's cloud infrastructure.

### Cloud Storage

Cloud Storage is an object storage service for files, backups, media, and application data.

### Virtual Private Cloud

Google Cloud Virtual Private Cloud (VPC) provides networking for cloud resources.

### Cloud IAM

Cloud Identity and Access Management helps organizations control access to Google Cloud resources through roles and permissions.

## Three Advantages

- Google Cloud provides strong services for data, AI, and machine learning workloads.
- Its infrastructure supports applications across different regions.
- Google Kubernetes Engine provides managed Kubernetes capabilities.

## Typical Enterprise Use Cases

Google Cloud can be used for application hosting, data analytics, AI and machine learning projects, cloud storage, and containerized applications.
