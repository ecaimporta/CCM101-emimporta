# Laboratory 04 - Cloud-Native Engineer

## Overview

This laboratory activity introduces cloud-native concepts, virtualization, containers, and Docker deployment.

## Objectives

- Understand the difference between virtualization and containers.
- Learn basic Docker commands.
- Create and manage a Docker container.
- Deploy an NGINX web server using Docker.
- Document the container lifecycle.

## Tools Used

- Killercoda
- Ubuntu
- Git
- GitHub
- Docker
- NGINX

## Activities

1. Compare virtualization and containers.
2. Pull the NGINX Docker image.
3. Run NGINX as a container.
4. Check the running container.
5. Stop and remove the container.
6. Document the Docker deployment process.
