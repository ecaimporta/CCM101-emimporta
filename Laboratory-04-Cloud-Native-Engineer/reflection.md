# Reflection

This laboratory helped me understand the basic concepts of cloud-native technologies, virtualization, containers, and Docker.

I learned how containers can be used to package and run applications in a consistent environment. I also learned the basic Docker commands used to pull an image, run a container, check its status, stop it, and remove it.

The activity helped me understand the difference between virtual machines and containers. Virtual machines use separate operating systems, while containers share the host operating system kernel.

Overall, this laboratory gave me a better understanding of how Docker can be used to deploy and manage applications.
