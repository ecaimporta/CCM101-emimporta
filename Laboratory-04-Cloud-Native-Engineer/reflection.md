# Reflection

This laboratory activity helped me understand the difference between Virtual Machines and Containers. Virtual Machines require a complete operating system, while containers share the host operating system, making them faster and more lightweight.

I learned how Docker simplifies application deployment through containerization. By using Docker commands, I was able to pull an Nginx image, create a container, test the web server, and manage the container lifecycle. The port mapping command `-p 8080:80` helped me understand how users can access services running inside containers.

I also learned that removing a container using `docker rm` permanently deletes the container, so proper management is important. Containers can improve collaboration between developers and IT operations teams because applications can run consistently across different environments.

This activity also improved my technical documentation skills using Markdown and GitHub. Adding this laboratory activity to my portfolio shows my growing knowledge of Docker, cloud-native technologies, and container management.
