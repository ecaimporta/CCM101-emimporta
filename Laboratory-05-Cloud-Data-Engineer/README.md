# Laboratory Activity 5 - The Cloud Data Engineer

## Mission Overview

This laboratory activity gave me hands-on experience with cloud storage. I first compared the common storage types and then deployed MinIO using Docker. After starting the storage server, I accessed its web interface, created a bucket, and uploaded a file as an object.

## Objectives

- Differentiate Block, File, and Object Storage.
- Determine an appropriate storage type for a photo-sharing application.
- Deploy an S3-compatible MinIO server using Docker.
- Practice Docker port mapping and environment variables.
- Access MinIO through its web console.
- Create a bucket and store an object.
- Record the completed work using Markdown and GitHub.

## Tools Used

- KillerCoda Ubuntu Playground
- Docker
- MinIO
- Git
- GitHub
- Web Browser
- Markdown

## Skills Learned

Through this activity, I learned how Object Storage works beyond its definition. Deploying MinIO allowed me to see how a storage service can run inside a Docker container and still be managed from a web browser. I also practiced creating a bucket, uploading an object, using environment variables, and checking a running container. The activity gave me a clearer idea of how cloud applications can store large amounts of unstructured data.
