# Laboratory 02 - Build the Cloud Infrastructure Blueprint

## Mission Overview

The purpose of this laboratory activity was to examine the resources found in a Linux cloud environment and understand how they relate to cloud infrastructure. I used KillerCoda to investigate different server resources and Linux system information. I also studied the services of three major cloud providers and created a diagram showing how basic cloud infrastructure components can be connected.

## Objectives

- Examine the resources and system information of a Linux server.
- Understand the main components that make up cloud infrastructure.
- Describe the functions of compute, storage, networking, and operating system resources.
- Explore and compare AWS, Microsoft Azure, and Google Cloud Platform.
- Develop a simple cloud infrastructure architecture.
- Record the laboratory findings and outputs through GitHub.

## Cloud Infrastructure Components

The following major components were examined during the laboratory:

- **Compute Resources** - Handle the processing of instructions, programs, and workloads in a cloud environment.
- **Storage Resources** - Keep the operating system, application files, and other forms of data.
- **Networking Resources** - Enable communication and connectivity among servers, users, and other resources.
- **Operating System** - Controls the system resources and provides a platform where programs and commands can operate.

## Tools Used

- **KillerCoda** - Used to access and investigate a Linux cloud environment.
- **Linux Terminal** - Used for executing commands and viewing system information.
- **GitHub** - Used for maintaining the files, documentation, and evidence of the laboratory activity.
- **Canva** - Used for designing the cloud infrastructure architecture diagram.

## Linux Commands Executed

- `cat /etc/os-release` - Shows information about the installed operating system.
- `uname -r` - Shows the current Linux kernel version.
- `lscpu` - Provides information about the processor and CPU resources.
- `free -h` - Shows the amount of system memory in a readable format.
- `df -h` - Shows disk usage, capacity, available space, and mounted file systems.
- `hostname` - Identifies the hostname assigned to the server.
- `hostname -I` - Displays the IP address or addresses assigned to the server.

## Skills Learned

I learned how basic Linux commands can be used to collect important information about a server and its available resources. The activity helped me understand that compute, storage, networking, and the operating system have different functions but work together to support a cloud environment.

I also gained knowledge about the core services available from AWS, Microsoft Azure, and Google Cloud Platform. Creating the architecture diagram helped me visualize how users, networks, compute resources, and storage resources can interact within a cloud infrastructure.

## Challenges Encountered

One challenge I encountered was interpreting the information displayed in the Linux terminal. Some commands produced several lines of technical information, especially when checking the CPU and mounted file systems, which made it difficult to identify the specific details required in the report. I addressed this by reviewing the output carefully and matching the needed information with each requirement.
