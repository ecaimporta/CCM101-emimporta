# Mission Reflection

## What did you learn from investigating the Linux environment?

The Linux investigation helped me understand that a cloud server is made up of different resources that can be examined individually. By using terminal commands, I learned that information about the CPU, memory, storage, operating system, and network can be viewed directly. This made the idea of cloud infrastructure easier for me to understand.

## How do compute, storage, and networking resources work together?

These resources work together as parts of one infrastructure. When a user sends a request through a network, the compute resource can process the request while the storage resource provides or saves the necessary data. Networking allows these resources to communicate and makes the service accessible to users.

## What did you learn from comparing AWS, Azure, and Google Cloud Platform?

I learned that AWS, Microsoft Azure, and Google Cloud Platform provide many similar cloud capabilities even though they are different platforms. Their services can support computing, storage, networking, and access management. The comparison also showed me that organizations can select a provider depending on their existing technologies and requirements.

## Which cloud infrastructure component do you think is the most important and why?

For me, storage is one of the most important components because applications and organizations need a reliable place to keep their files and data. Processing and communication are also important, but many cloud services depend on stored information to operate properly.

## How can you apply what you learned to real-world cloud systems?

I can apply what I learned by looking at a cloud system as a group of connected resources instead of just one service. When designing or studying a cloud architecture, I can identify where processing happens, where information is stored, and how users connect to those resources. This understanding can help me create and analyze more complex cloud architectures in future activities.
