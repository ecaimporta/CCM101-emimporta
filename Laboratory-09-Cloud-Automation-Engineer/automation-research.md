# Automation Research

## Bash Script and Shebang

A Bash script is a file containing commands that Linux can execute in sequence to automate tasks. The line `#!/bin/bash` is called the shebang and tells the system to use Bash to run the script.

## Variables

Variables store values that a script can reuse. For example, `$BACKUP_DIR` stores the backup directory path. Using a variable makes the script easier to maintain because the path can be changed in one place.

## Cron Job

A cron job is a scheduled task in Linux that runs automatically at a specified time or interval. It is useful in cloud operations for recurring tasks such as backups and maintenance.
