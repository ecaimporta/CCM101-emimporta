# Laboratory 06 - Cloud Deployment Engineer

## Mission Overview

This mission introduced the use of Docker Compose for deploying a two-tier private cloud storage application. The project combined Nextcloud with a MariaDB database and connected the two services through a Compose configuration.

## Objectives

- Explain the basic idea of a multi-tier application.
- Create a Docker Compose YAML configuration.
- Deploy Nextcloud and MariaDB as connected services.
- Access the Nextcloud setup page through port 8080.
- Practice documenting a containerized cloud deployment.

## Commands Executed

docker-compose up -d

docker-compose ps

docker-compose down

## Skills Learned

I learned how Docker Compose can coordinate several containers from one configuration file. I also practiced creating YAML configuration files, checking running services, accessing an application through a mapped port, and documenting the deployment process using Markdown.
